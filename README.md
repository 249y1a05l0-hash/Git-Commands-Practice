# Git Commands Practice

This repository demonstrates basic Git commands used for version control. It is created as part of an academic assignment.

 Commands Included

- git init
- git status
- git add
- git commit
- git branch
- git checkout
- git merge
- git pull
- git push
- git clone
- git log
- git rm

 Description

Git is a distributed version control system used to track changes in source code. This project shows commonly used Git commands in a simple and clear format.

 Usage

Run the following commands in your terminal:

```bash
git init
git add .
git commit -m "Initial commit"
git push -u origin main
